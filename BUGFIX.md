# Исправление багов

При проверке конструктора проекта нашла несколько проблем с выбором и добавлением услуг.

### 1. Не выбиралась услуга
`selectedServiceId` хранился в обычной переменной. При выборе пункта значение менялось, но React не обновлял компонент, поэтому выбор не отображался.

**Исправила:** перенесла `selectedServiceId` в `useState` и обновляю его через `setSelectedServiceId`.

### 2. Не менялось количество
С `quantity` была та же проблема: значение изменялось напрямую, без обновления состояния React.

**Исправила:** использовала `useState` и `setQuantity`.

### 3. Услуги не появлялись в таблице
Список `selectedServices` был обычным массивом, который заново создавался при каждом рендере. Кроме того, `push()` менял массив напрямую, поэтому React не получал сигнал об обновлении интерфейса.

**Исправила:** перенесла список в `useState`, а новые услуги добавляю через `setSelectedServices`, создавая новый массив.

### 4. Повторное добавление услуги
При повторном добавлении количество увеличивалось через `existing.quantity += quantity`. Это прямое изменение объекта внутри массива состояния, из-за чего React мог не отобразить новое значение.

**Исправила:** обновляю нужный элемент через `map()`, создавая новый объект с изменённым количеством.

### 5. Удаление услуги
В `removeService()` использовался `splice()`, который напрямую изменял массив. Из-за этого список не обновлялся корректно.

**Исправила:** заменила `splice()` на `filter()` и обновляю список через `setSelectedServices`.

### Дополнительно
Добавила проверку количества перед добавлением услуги, чтобы нельзя было добавить ноль, отрицательное или некорректное количество. Расчёт итоговой суммы менять не пришлось: теперь он обновляется при изменении списка услуг.
